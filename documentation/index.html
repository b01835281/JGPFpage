    • Element5 (Scene Swapper) Documentation

    The element consists of an interactive screen between two scenes. Both scenes are visibly identical, with the difference of lighting and direction of rotation of the Rabbit Cube.

    The user is presented with two buttons to swap between the scenes respectively. However, each time the buttons are pressed, the speed of the rotating Rabbit Cube will increase.

    Unlike how previous work has been split between a "createStartScene" and a "runStartScene" working side by side, I have merged them into a singular "createStartScene" to allow the object animation without the need of a multi-file structure like previous work.
